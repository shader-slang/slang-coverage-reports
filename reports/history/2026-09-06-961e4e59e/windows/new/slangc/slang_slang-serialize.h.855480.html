     980              : // Serialization of pointers is the most complicated part of

     982              : //

     988              : // * Types that require going through a factory function of

     996              : //   pointer types `T*` and dispatched out to `serializePtr(s,v,(T*)nullptr)`.

    1002              : //   invoke either `serializeUniquePtr` or `serializeSharedPtr`, which
