       5                         : // NonUniform propagation for SPIR-V
       6                         : // ==================================
       7                         : //
       8                         : // When a shader indexes a resource array with NonUniformResourceIndex(idx),
       9                         : // Vulkan (VUID-RuntimeSpirv-None-10148) requires the NonUniform decoration
      10                         : // on the resource operand consumed by the sampling/memory instruction.
      11                         : //
      12                         : // Target applicability
      13                         : // --------------------
      14                         : // This pass runs for every target (see the two callers below), but the two
      15                         : // floatModes do very different amounts of work, and the heavy propagation in
      16                         : // this file matters for exactly one target: the direct SPIR-V backend.
      17                         : //
      18                         : //   * SPIRV mode (called from slang-ir-spirv-legalize.cpp): the direct SPIR-V
      19                         : //     emitter is the only backend with no downstream shader compiler, so Slang
      20                         : //     itself must attach OpDecorate NonUniform to every consumed resource
      21                         : //     operand to satisfy VUID-RuntimeSpirv-None-10148. That is why this mode
      22                         : //     bubbles the wrapper all the way to the leaf and then runs the decoration
      23                         : //     phase (decorateNonUniformChain + the legalize forward scan).
      24                         : //
      25                         : //   * Textual mode (called from slang-emit.cpp for all !isSPIRV targets): no
      26                         : //     decoration is emitted (the function returns before the decoration phase).
      27                         : //     The pass only repositions the NonUniformResourceIndex wrapper so it ends
      28                         : //     up wrapping the index expression; the rest is the source emitter's job.
      29                         : //     Per each target's own spec, the non-uniform concept lives on the *index*
      30                         : //     (and the downstream compiler propagates it) or does not exist at all:
      31                         : //       - HLSL: re-emitted as the textual `NonUniformResourceIndex(index)`
      32                         : //         hint. The D3D spec defines it as a hint applied to the indexing
      33                         : //         expression (indices are wave-uniform by default); DXC/FXC then
      34                         : //         propagates correctness to the consumed resource. So Slang only needs
      35                         : //         the wrapper on the index. (DirectX-Specs: Resource Binding, "Shader
      36                         : //         Derivatives and Divergent Indexing"; SM 6.6 Dynamic Resources.)
      37                         : //       - GLSL: re-emitted as `nonuniformEXT(index)`. GLSL *does* support
      38                         : //         non-uniform indexing -- the GL_EXT_nonuniform_qualifier spec defines
      39                         : //         `nonuniformEXT` as a qualifier/constructor applied to the index or
      40                         : //         expression -- and glslang propagates it downstream. (Khronos
      41                         : //         GL_EXT_nonuniform_qualifier.)
      42                         : //       - Metal / WGSL / CUDA / CPU: the wrapper is dropped at emit time (the
      43                         : //         CLikeSourceEmitter base just emits operand 0), because none of these
      44                         : //         have a non-uniform-resource-indexing annotation to carry:
      45                         : //           . Metal allows dynamic/non-uniform indexing of argument-buffer
      46                         : //             resource arrays with no shader-side qualifier (Metal Shading
      47                         : //             Language Spec 2.13 Argument Buffers; Tier 2 bindless).
      48                         : //           . WGSL/WebGPU has no non-uniform annotation: binding arrays are
      49                         : //             still proposal-stage and, per that proposal, "do not require
      50                         : //             explicit non-uniform annotations" (gpuweb sized-binding-arrays).
      51                         : //           . CUDA/CPU have no descriptor-array / bindless concept at all.
      52                         : //         There is nothing to propagate, so doing more here would have no
      53                         : //         target syntax to emit it into.
      54                         : //
      55                         : // So the decoration machinery below is intentionally SPIR-V-only: every other
      56                         : // target either delegates propagation to its downstream compiler (HLSL, GLSL)
      57                         : // or has no way to express the concept (Metal, WGSL, CUDA, CPU).
      58                         : //
      59                         : // Two passes cooperate to achieve this for SPIR-V, and both live in this file:
      60                         : //
      61                         : // 1. Float pass (processNonUniformResourceIndex / floatNonUniformResourceIndex):
      62                         : //    Bubbles the NonUniformResourceIndex wrapper outward through the
      63                         : //    use-def chain (GetElement, Load, MakeCombinedTextureSampler,
      64                         : //    CombinedTextureSamplerGetTexture, ImageTexelPointer, etc.).
      65                         : //    When the wrapper reaches an instruction the pass cannot float
      66                         : //    through (e.g. the spirv_asm boundary), the decoration phase
      67                         : //    walks back through the chain via decorateNonUniformChain to
      68                         : //    attach IRSPIRVNonUniformResourceDecoration to the index and
      69                         : //    all intermediate resource-creating ops.
      70                         : //
      71                         : // 2. Forward scan (propagateNonUniformDecorations): A single forward
      72                         : //    linear scan that runs after the legalizer rewrites getElement to
      73                         : //    getElementPtr. Syncs NonUniform between access-chain indices
      74                         : //    and their instructions (bidirectional), and forward-propagates
      75                         : //    through Load, FieldAddress/FieldExtract, and ImageSubscript to
      76                         : //    reach the final resource operand.
      77                         : //
      78                         : // Resource-creating ops (MakeCombinedTextureSampler,
      79                         : // CombinedTextureSamplerGetTexture, ImageTexelPointer) are handled
      80                         : // exclusively by the float pass. The forward scan handles
      81                         : // access chains, loads, field accesses, and image subscripts.
      82                         : //
      83                         : // ImageSubscript is a forward case (not a float-pass case) because it
      84                         : // is never converted to a kIROp_ImageTexelPointer IR inst -- it lowers
      85                         : // directly to SpvOpImageTexelPointer at emit time, so the decoration
      86                         : // must land on the ImageSubscript inst itself. This mirrors how the
      87                         : // HLSL `RWTexture[coord]` __ref-accessor atomic path differs from the
      88                         : // GLSL imageAtomic* path that uses kIROp_ImageTexelPointer directly.
      89                         : //
      90                         : // Invocation / ownership
      91                         : // ----------------------
      92                         : // This file owns the NonUniform logic, but it does not schedule itself; the
      93                         : // callers decide when each phase runs:
      94                         : //
      95                         : //   * Textual mode: floatNonUniformResourceIndex(module, Textual) runs as a
      96                         : //     standalone SLANG_PASS from slang-emit.cpp (the IR lowering pipeline) for
      97                         : //     all non-SPIR-V targets. It only repositions the wrapper; it emits no
      98                         : //     decorations, and the forward scan is NOT run.
      99                         : //
     100                         : //   * SPIR-V mode: both phases are scheduled by the SPIR-V legalize pass
     101                         : //     (SPIRVLegalizationContext::processModule in slang-ir-spirv-legalize.cpp):
     102                         : //       - the float phase runs per-instruction, dispatched from the legalize
     103                         : //         worklist as the kIROp_NonUniformResourceIndex handler
     104                         : //         (processNonUniformResourceIndex(..., SPIRV));
     105                         : //       - propagateNonUniformDecorations(module) runs once, as the FINAL step
     106                         : //         of processModule.
     107                         : //     The forward scan must run last (after getElement -> getElementPtr,
     108                         : //     buffer-to-pointer lowering, legalizeStructBlocks, and force-inlining)
     109                         : //     because it decorates the resulting emit-shape access chains / loads /
     110                         : //     field accesses / image subscripts, which do not exist in final form
     111                         : //     earlier. That ordering constraint is why its invocation stays in the
     112                         : //     legalize pipeline even though its code lives here.
