 5// This file provides the `EndToEndCompileRequest` type and
 6// related utilities.
 7//
 8// The primary purpose of `EndToEndCompileRequest` is to
 9// implement the overall flow of compilation for the
 10// `slangc` command-line tool. Command-line compiles need
 11// to deal with various details that aren't relevant to
 12// API-based compiles (e.g., writing output to files),
 13// and also need to implement a lot of complicated
 14// "do what I mean" policy that is expected by users of
 15// `slangc` but that can be dangerously implicit when
 16// that policy is enshrined in an API.
 17//
 18// In addition to serving the needs of `slangc`, the
 19// `EndToEndCompileRequest` type also implements the
 20// deprecated `slang::ICompileRequest` interface from
 21// the public API.
 22//
