 458    // * No additional instructions are needed in the body of
 459    //   the callee; the global G should stand in for P.
 460    // * The global G should be used to distinguish this specialized
 461    //   callee from those that might be specialized for a different
 462    //   global shader parameter.

 465    // but A is now an indexing operation into an array: `G[idx]`:

 468    // * A parameter `p_idx` with the same type as `idx` should be added
 469    //   to the specialized callee.
 470    // * An instruction should be added to the specialized callee

 473    //   call site from others.
 474    //
 475    // That's a lot of examples, I know, but hopefully it gives a
 476    // sense of the information we are tracking and how it differs
 477    // across the various cases. While the example only covered one
 478    // level of indexing, the actual implementation will handle the
 479    // case of arbitrarily many levels of indexing, which can mean
 480    // piping through any number of additional integer parameters
 481    // to the callee.

 485    // argument list, and the "key" information that distinguishes
 486    // what specialized callee we want/need.
 487    //
